# Property descriptions

## Before drafting

1. Ask for the sources if none have been given: website link, fact sheet, existing listing, uploaded documents.
2. Ask which channel it's for and its character limit.
3. Ask whether there's an approved structure to follow. If there is, it's locked.

## Rules

- **Verified sources only.** Every detail must be traceable to a source the user gave you. Never invent or assume amenities, distances, views or policies.
- **Keep everything in the source.** Don't drop any item unless the user explicitly says to. Shorten wording, not facts.
- **Neighbourhood first.** Short and booking-site descriptions open with the area, then the property.
- **Locked structure.** Once a structure is approved, keep its order and format in every later draft unless told otherwise.
- **Gaps are "To confirm".** If the channel needs something the sources don't cover, write "To confirm" and list it at the end.
- **Brand voice.** If a brand-voice skill or guide exists, follow it.

## Default structure (when none is approved)

1. Neighbourhood
2. The property
3. Rooms
4. Facilities
5. Practical details

## Deliver

1. The description, within the character limit
2. A short list mapping any detail that might be questioned to its source
3. Anything marked "To confirm"
4. Anything from the source you couldn't fit, so the user can decide
