# Side-project brand page

A one-page template for showing a side project's brand identity: brief, logo, colour, type, voice and the brand in use. It's a single HTML file with no build step, and it works on phones.

I'm using it for my own personal projects: a walking-and-pub group I named and branded for my friends, and a food-writing project.

## Use it

1. Copy [`index.html`](index.html) into a new repo, or a folder in this one.
2. Change the colours and fonts in the `:root` block at the top.
3. Swap the placeholder text and add your images to an `assets` folder.
4. Turn on GitHub Pages (Settings, then Pages, then deploy from the main branch) and it's live.
